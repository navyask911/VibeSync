# Contributing to VibeSync

Copyright © 2026 VibeSync. All rights reserved.

VibeSync is proprietary software. Contributions, patches, bug reports, and suggestions must respect the proprietary license and must not introduce third-party code without a compatible license.

Security issues must be reported privately through the process in `SECURITY.md`. Never post credentials, service-account files, personal data, or exploit material in public issues.

All changes must preserve the VibeSync architecture: Supabase is authoritative application backend, Firebase is FCM-only, Room is local-first, Google Tink is the application cryptography boundary, and server secrets remain server-side.
