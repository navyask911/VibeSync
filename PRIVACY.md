# VibeSync Privacy Policy

**Effective date: October 7, 2026**

VibeSync is designed around data minimization and privacy-first architecture.

## Contact discovery
VibeSync is designed so the device address book is not stored as a permanent cloud database. Contact information should be processed locally where possible, transformed into privacy-preserving identifiers, and only the minimum information needed for matching should be transmitted.

## Messages
VibeSync is designed for client-side encryption of supported private communications. Encryption claims apply only to protocols explicitly implemented and documented in the production release.

## Push notifications
Firebase Cloud Messaging may be used for Android push notifications. Firebase is not intended to be VibeSync's primary application database.

## Media
Large media may be stored in configured object storage providers using authenticated or time-limited access.

This policy is a product baseline and should be reviewed by qualified legal counsel before public launch.
