# VibeSync Security Policy

## Security objectives
Least privilege, Supabase Row Level Security, server-side secrets, local-first data minimization, Google Tink cryptography, privacy-preserving contact discovery, time-limited media access, server-authoritative business transactions, and auditable builds.

## Firebase boundary
Firebase is retained for FCM push notifications. Firestore, Realtime Database, Firebase Storage, and Firebase Authentication are not intended to be authoritative VibeSync application backends.

## Important limitation
No software can honestly be promised to be completely hack-free. VibeSync uses defense-in-depth, secure defaults, continuous testing, and prompt remediation.
